# Remix of Smart Produce Guide

Build AgriVision AI, a premium AI-powered consumer grocery decision intelligence platform designed as a future-ready smart wearable experience. The product helps users choose the best fruits and vegetables by analyzing uploaded images and providing contextual recommendations rather than simple detection. The core workflow is: Upload or scan produce → AI analyzes color, texture, ripeness, spots, and spoilage indicators → Food-state classification → Confidence scoring → Intent matching → Recommendation output. Users can select intents such as Eat Today, Store for 2 Days, Store for 1 Week, Cooking, or Smoothie, and the system should dynamically recommend Best Pick, Store Later, Use Soon, or Avoid with clear reasoning. The hero feature is Comparison Intelligence, where multiple produce items are compared side-by-side and ranked according to the user's intended use. Create a beautiful Apple-inspired UI using a deep blue, white, and green color palette with premium typography, glassmorphism, smooth animations, and responsive design. Include a landing page, dashboard, produce scan page, comparison page, learning mode, scan history, settings page, and future smart-specs showcase section. Build both frontend and backend inside Lovable with authentication, database, image uploads, scan history, recommendation engine, comparison engine, confidence scoring, and educational learning mode. Use Supabase for database, storage, authentication, and backend services. Generate realistic mock AI outputs and structured data models. The application should feel like a real startup product focused on wearable grocery guidance, contextual recommendation, and comparison-based decision making, not a farmer advisory or crop disease platform. The final result should look production-ready, scalable, investor-grade, and suitable for demonstrating the AgriVision AI concept at Aggnite 6.0.
